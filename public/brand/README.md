# Approved Chi-Rho clock logo

`chi-rho-clock-v1.png` is the transparent symbol adapted with image_gen from the exact logo approved on 2026-09-27. The source was the selected image-edit target ending `acb72c9e4577a23a.png`.

The website renders its name as native Vietnamese text beside this symbol. The app-icon route renders the same artwork at the sizes required by the header, completion screen, browser favicon and installed app. App icons include an ivory background and padding for maskable launchers. Header marks have transparent backgrounds and gain an ivory circular backing in dark mode.

`lib/brand.mjs` centralizes versioned URLs and offline assets. Increment the version and source filename together when replacing the artwork; this avoids stale icons in long-lived browser caches.
