# Vietnamese prayer fonts

Self-hosted subsets of Noto Sans and Noto Serif, licensed under the SIL Open Font License 1.1. The accompanying OFL files preserve the copyright and license notices.

Sources: https://github.com/google/fonts/tree/main/ofl/notosans and https://github.com/google/fonts/tree/main/ofl/notoserif (downloaded 2026-09-27).

Built with FontTools from the upright variable fonts, with width fixed at 100 and weight range 400–800. Unicode coverage includes Latin characters, Vietnamese base letters and tone marks, combining diacritics, punctuation and the interface symbols. All OpenType layout features are retained for accent placement.

The fonts are served by next/font/local, preloaded by the page and included when saving the page for offline use. No font request goes to Google at runtime.
